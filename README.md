# FoveaEdge

## Event-Driven Foveated Inference for High-Resolution Edge Vision

FoveaEdge is an experimental OpenVINO-based edge vision pipeline investigating whether spatially selective, event-driven inference can reduce computational cost while preserving small-object detection performance in high-resolution video.

### Research Question

Can a system dynamically allocate high-resolution inference only to important regions of a scene while maintaining useful accuracy and predictable latency on commodity edge hardware?

### Current Status

🚧 Research and development — Day 1

### Goals

- OpenVINO-based inference
- High-resolution video processing
- Event-driven region-of-interest generation
- Dynamic inference scheduling
- Asynchronous execution
- Hardware-aware optimization
- Reproducible benchmarking

### Research Integrity

This project does not claim novelty merely because a particular combination of techniques has not been found yet.

Existing OpenVINO functionality, research, and implementations will be investigated and documented before making novelty claims.

All performance numbers will be measured on actual hardware.
